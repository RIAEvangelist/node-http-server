From v8 to v9

Check the deliberate changes.

Most server configuration remains familiar. These are the changes worth handling first.

Listen addressThe default is 127.0.0.1. Set host explicitly for network access.

Behaviorv9 result
MethodsStatic fallback serves GET/HEAD; other methods receive 405.
Conditional requestsWeak ETags and Last-Modified validation can return 304.

Safe starting point

Public exposure is a decision.

The server starts on loopback. Binding to another interface is deliberate, visible configuration—not a surprise.

Read the full security model →

Default boundary

your machine 127.0.0.1

To accept network traffic, set host yourself.

Before network exposure

Make each boundary explicit.

01

Bind narrowly.

Keep 127.0.0.1 for local tools. Set another host only behind deliberate network controls.

02

Limit what arrives.

Set body limits and timeouts for the traffic profile. Unlimited and disabled values are opt-in choices.

03

Choose served types.

Use restrictedType for 403, a false MIME entry for 415, or disable automatic MIME mapping.

04

Protect logs.

Credential headers are redacted, but paths, addresses, and optional bodies remain sensitive.

05

Bring your own TLS.

Use fresh certificates and protect private keys. Do not commit local secrets.

06

Do not trust v8 fixtures.

Old fixture keys may exist in copies or history. They are public and untrusted. Never use them.
