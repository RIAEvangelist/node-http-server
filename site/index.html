01 / HTTP

Files behave like files on the web.

Streaming responses, HEAD, byte ranges, ETags, and modified-time validation are built into the core.

02 / SAFE

Local until you say otherwise.

The default bind address is 127.0.0.1. Path containment keeps requests inside the configured root.

03 / CONTROL

Limits are yours.

Request-body limits, timeouts, and compression are explicit, settable options. The body limit stays off until you opt in.

04 / APPS

Single-page apps included.

Turn on SPA fallback for client-side routes. Leave it off for a strict static file server.

05 / LIFECYCLE

Run one. Run many. Close cleanly.

Create isolated Server instances for separate ports and roots. Await close() when the work is done.
