Developer guide

Small API. Explicit options.

Start with CommonJS, ESM, or the CLI. Open only the reference table you need.

Start API Configuration CLI Scripts

Install and start

Use either module system.

Node.js 22.12 or newer is required. Both examples create an isolated server instance.

CommonJS
const {Server}=require('node-http-server');

const server=new Server({root:'./public'});
server.deploy();
ESM
import {Server} from 'node-http-server';

const server=new Server({root:'./public'});
server.deploy();
npm install node-http-server

Complete reference

The contract, in tables.

Defaults are explicit. Optional behavior stays optional.

APILifecycle, exports, hooks, and public members
MemberReturnsPurpose

close(callback?)Promise<void>Close every listener owned by this instance; the instance can deploy again.

serve(request,response,body,encoding)PromiseComplete a manual response through hooks.
serveFile(filename,request,response)Promise<boolean>Serve a deliberate file from custom code.
onRawRequest(request,response,serve)truthy takeoverIntercept before parsing; receives the public safe serve path.
onRequest(request,response,serve)truthy takeoverIntercept after parsing; receives the public safe serve path. request.body is text and bodyBuffer is a Buffer.
beforeServe(request,response,bodyRef,encodingRef,complete)truthy takeoverModify buffered output; completion is one-shot and does not re-enter the hook.
afterServe(request,response)void/PromiseObserve completed responses.
configConfigThe instance's isolated configuration.
server / secureServerNode server or nullActive HTTP and HTTPS listeners.
default exportServer singletonThe original shared server from both CommonJS and ESM.
named exportsconstructorsServer, Config, and RefString.

Listener failures keep Node's native event contract. Attach server.server.once('error', handler) after deploy() when your application handles bind errors. lastError records request, hook, stream, and log failures.
